# Demo Skills
These have been developed by Civis to help with non-profit data analysis and reporting. Downloading them and installing them in your claude environment can help improve Claude's ability to respond to your questions on specific topics.

## Report builder skils
Two report builder skills help claude build html reports that can be automated in the Civis platform. The simple skill will build a single Python script which can be copied directly into a Civis Python script and then scheduled to run on a specific cadence. By building a report this way you'll be able to create a simple html report that provides useful reporting and is updated on a regular cadence using your data warehouse.

The second report builder skill is for users who already have github set up and want the ability to develop more advanced reports. This skill will scaffold a project with folders designed to segment code by type and use case in order to keep your reports well organized. For users who like to version control their code or would like to develop more complex multi tab reports this is often a better option. 

If you install both skills Claude will help you decide which one to use based on your set up and goals.
